# Demo · control digital de construcción

Portal de demostración de una plataforma de control de obra para una línea de transmisión de 138 kV (19 torres, doble terna)
y tres subestaciones: BIM 4D, BIM general con relieve y ortofoto, curva S y pronóstico, fotos de obra identificadas por IA,
eventos y reportes diarios.

**Todos los datos son ficticios**: nombres, ubicación, cotas, avances y metrados están cambiados; no hay montos ni nombres de
personas; las fotos de obra no muestran personas, logos ni sellos y no llevan metadatos.

Abrir: `index.html` (portada) · `tablero.html` (línea) · `bim-general/` · `se-rio-claro/` · `se-cerro-azul/` · `se-pampa-alta/`.
El relieve (Terrain Tiles, AWS) y la ortofoto (Esri World Imagery) se piden desde el navegador de quien abre la página.
